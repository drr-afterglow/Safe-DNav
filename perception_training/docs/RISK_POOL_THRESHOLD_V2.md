# v2 阈值风险池化对照

更新时间：2026-07-30

## 目的

比较校准阈值 0.60 与高召回阈值 0.50 对 6x36 风险池化的影响。使用独立运动风险验证集和冻结测试集，包含完整 FLU 三维自机速度。

当前运行时策略为每个池化单元保留最近预测动态回波，因此主要比较 `nearest`；同时记录预测 TTC 策略作为参考。

## 验证集

样本数 1800，风险单元 4246。

| threshold | 预测可用率 | nearest 风险目标保留 | nearest 平均 oracle 风险 | pred_ttc 风险目标保留 |
|---:|---:|---:|---:|---:|
| 0.50 | 0.92181 | 0.90862 | 0.82839 | 0.90909 |
| 0.60 | 0.91616 | 0.90532 | 0.82522 | 0.90626 |

验证集选择 0.50。

## 冻结测试集

有效样本 1799，风险单元 4168。

| threshold | 预测可用率 | nearest 风险目标保留 | nearest 平均 oracle 风险 | nearest oracle 赢家率 | pred_ttc 风险目标保留 |
|---:|---:|---:|---:|---:|---:|
| 0.50 | 0.94410 | 0.91915 | 0.84330 | 0.45753 | 0.92083 |
| 0.60 | 0.93954 | 0.91723 | 0.84155 | 0.45609 | 0.91939 |

冻结测试集与验证集方向一致。0.50 相比 0.60：

- 预测可用率提高 0.456 个百分点；
- nearest 风险目标保留提高 0.192 个百分点；
- nearest 平均 oracle 风险保留提高 0.175 个百分点；
- pred_ttc 风险目标保留提高 0.144 个百分点。

## 结论

采用双阈值：

- **0.60**：离线分割评估和低误报标准模式；
- **0.50**：PPO/CBF 导航风险池化与安全相关运行时模式。

风险池化继续使用已冻结的 nearest 策略。阈值 0.50 在验证集选定，并由冻结测试集确认。
