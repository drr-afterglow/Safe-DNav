# 12K 径向速度损失消融

更新时间：2026-07-30

## 实验目的与设置

下游 TTC/CBF 主要依赖相对径向速度。本实验检验提高径向速度 v_r 的异方差 Laplace 损失权重，能否降低径向误差并改善风险排序。

除速度分量权重外，网络、12K 固定划分、随机种子、FP32、batch size 256、80 轮、优化器、增强和 checkpoint 规则均与 FP32 基线一致。不叠加远距离分割权重。

原始分量权重为 [1,1,1]；实验权重为 [2,1,1]，训练内部归一化为 [1.5,0.75,0.75]，平均仍为 1，保持运动损失总尺度基本不变。梯度回归确认径向梯度恰为切向的 2 倍。

配置：perception_training/config/intermediate_12k_radial_weight_2x_fp32.yaml

最佳 checkpoint：第 63 轮，selection score 1.469382。

## 结论

径向 2x 没有达到核心目标：v_r MAE 未下降，反而增加 0.00255 m/s；两个切向分量和总体速度 MAE也明显恶化。因此不采用该权重。

分割与风险保留的小幅提升主要来自模型随机训练结果带来的检测率提升，而不是径向速度估计更准确，不能作为接受径向加权的依据。该 checkpoint 仅作为消融记录保留，不进入最终候选。
