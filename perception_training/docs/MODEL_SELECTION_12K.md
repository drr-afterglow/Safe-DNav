# 12K 候选模型选择

更新时间：2026-07-30

## 候选

- FP32 基线，mask threshold 0.50。
- 远距离动态正样本 Focal 2x，原始 threshold 0.50。
- 径向速度 2x 已因速度误差恶化而提前淘汰。

## 阈值校准

仅在验证集扫描远距离 2x 模型的阈值 0.50--0.60。阈值 0.60 时 Precision/FPR 与基线 0.50 最接近，因此冻结该工作点并在测试集确认。

## 最终决定

默认模型选择 FP32 基线第 63 轮，mask threshold 0.50。理由是总体 IoU/F1更高、速度 MAE更低、风险平均保留略高，整体最均衡，并且无需额外阈值偏移。

远距离 2x 模型不删除，作为需要偏高召回时的备选。其 threshold 0.50 可获得明显更高远距离 Recall，但会增加误检；threshold 0.60 可恢复误检率，但远距离收益缩小。径向速度 2x 不采用。
