# 12K 远距离分割损失消融

更新时间：2026-07-30

## 实验目的

验证 5--10 m 动态目标像素较少、在普通逐像素损失中监督不足，是否是远距离分割性能偏低的原因。

## 公平设置

除分割损失外，其余条件与 FP32 基线完全一致：

- SA-UMNet 结构、四通道输入不变；
- train/val/test 固定为 8400/1800/1800，场景隔离不变；
- 随机种子 0，FP32，batch size 256，训练 80 轮；
- AdamW、学习率、增强、速度损失和 checkpoint 选择规则不变；
- 仅将真实距离 >=5 m 的动态正样本 Focal 权重设为 2.0；
- Dice、远距离静态像素、近中距离像素均保持原权重。

配置：perception_training/config/intermediate_12k_far_weight_2x_fp32.yaml

最佳 checkpoint：第 62 轮，selection score 1.468994。

## 结论

实验支持“远距离正样本监督不足”的假设：远距离 Recall 提升 2.57 个百分点，远距离 IoU 提升 0.73 个百分点，运动风险保留没有退化。

代价是模型整体更偏向召回，Precision 下降 1.37 个百分点，FPR 增加 0.21 个百分点；总体 IoU 和 F1 仅轻微下降。该设置属于有效但存在精度--召回权衡的候选，不覆盖原 FP32 基线。两套 checkpoint 均保留，最终在径向速度消融及下游 PPO/CBF 联合比较后选择。
