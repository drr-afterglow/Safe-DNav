# 感知模块训练策略

当前阶段只采用固定/随机位姿离线采集，先把感知网络的监督学习链路训稳。

## 固定/采样位姿离线采集

先把无人机或传感器放在大量随机位姿上，让动态障碍物在视野中运动，采集点云、上一帧、当前帧和仿真真值标签。

优点：

- 更容易控制动态障碍物出现比例，解决动态 mask 正样本稀疏的问题。
- 可以覆盖近距离、远距离、边界经线、不同俯仰角、遮挡等困难样本。
- 不依赖 RL 策略质量，数据采集稳定。

这个阶段适合训练语义 mask、速度头和不确定性头的基础能力。

## 暂不处理的内容

暂时不做策略驱动的数据采集。当前只保留随机位姿离线采集，这样可以避免数据采集和模型优化相互耦合，先集中解决监督标签质量。

## 建议结论

用 `perception_training/data_collection/collect.py` 生成高覆盖率监督数据集，再用 `perception_training/train.py` 离线训练感知模块。真正接入 RL 前，先冻结感知网络做接口和观测分布验证。
