# 12K v2 Mask Threshold 校准

更新时间：2026-07-30

## 方法

- 仅使用 1800 条验证集样本选择阈值，冻结测试集不参与选型。
- 粗扫描范围为 0.30--0.75，步长 0.05。
- 在最优区间 0.56--0.64 内进一步以 0.01 步长扫描。
- 主要选择指标为总体 Mask IoU，辅助观察 F1、Precision、Recall、FPR 和远距离 IoU。

验证集总体 IoU 在 0.60 达到峰值，因此选择 0.60。

## 结论

- 默认分割阈值校准为 **0.60**，用于总体 IoU/F1 更优且误报更低的标准模式。
- **0.50** 保留为高召回、远距离和风险敏感备选。
- 风险池化验证需要同时比较 0.50 与 0.60，避免仅凭总体 IoU牺牲安全相关召回。
- v2 配置 `intermediate_12k_v2_fp32.yaml` 已更新为 0.60。
