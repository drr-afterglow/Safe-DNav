# SA-UMNet 感知评估体系

本文档说明如何评价 SA-UMNet 是否适合无人机动态环境导航。评估不只关注网络能否找到障碍物，还要检查速度预测、不确定性、危险信息保留和全景边界表现。

## 一、动态障碍物能否被发现

使用以下指标评价动态 mask：

- **Precision（精确率）**：网络报告的动态像素中，有多少确实属于动态障碍物。
- **Recall（召回率）**：所有真实动态像素中，有多少被网络成功发现。
- **F1**：综合衡量 Precision 和 Recall。
- **IoU**：预测动态区域与真实动态区域的重合程度。
- **FPR（误报率）**：静态像素被错误判断为动态像素的比例。

无人机安全导航尤其关注 Recall，因为漏掉正在接近的障碍物通常比多报一个障碍物更危险。但 Recall 不能单独使用，否则网络可能把大量静态区域都判断为动态，因此必须结合 Precision、IoU 和 FPR 一起分析。

## 二、不同距离下是否可靠

总体指标可能掩盖近距离目标漏检问题，因此默认按距离分为：

- `0--2 m`：最危险的近距离区域；
- `2--5 m`：主要避障区域；
- `5--10 m`：远距离感知区域。

每个距离区间分别统计动态 Recall、IoU 和真实动态像素数量。距离由当前帧归一化深度乘以雷达最大量程得到。

## 三、障碍物速度预测是否准确

SA-UMNet 输出三个球坐标速度分量：

- `v_r`：径向速度，表示障碍物正在接近还是远离无人机；
- `v_theta`：水平方位角方向速度；
- `v_phi`：垂直俯仰方向速度。

每个分量分别统计：

- **MAE**：平均绝对误差，容易直观理解；
- **RMSE**：对较大的速度误差更加敏感。

径向速度 `v_r` 对安全导航最重要，因为 CBF 需要利用它判断障碍物是否正在快速接近。

## 四、静态区域是否产生虚假速度

静态环境的真实速度应为零。如果网络在墙壁、地面等静态区域预测出较大速度，会给 PPO 或 CBF 造成错误危险信息。

系统统计静态有效区域预测速度模长的：

- 平均值；
- 95% 分位数（P95）。

P95 用于发现少量但严重的虚假速度。为避免保存数百万个像素，代码使用固定内存直方图近似计算 P95，并同时报告超出直方图范围的比例。

## 五、网络能否正确表达不确定性

网络除了预测速度，还会预测对应的 `sigma`，表示网络认为速度估计有多不确定。评估内容包括：

- **Laplace NLL**：综合检查速度误差和不确定性是否匹配；
- **误差与 sigma 的相关性**：预测误差越大时，sigma 是否也会增大；
- **1 sigma 覆盖率**：真实误差落在一个 sigma 范围内的比例；
- **2 sigma 覆盖率**：真实误差落在两个 sigma 范围内的比例；
- 平均 sigma。

这些指标用于判断网络是否过度自信或过度保守。覆盖率必须按照当前使用的 Laplace 分布解释，不能直接套用正态分布的固定比例。

## 六、降采样后危险目标是否被保留

网络输出为 `16x180`，而 PPO 使用 `6x36`。降采样可能丢失面积很小但速度很快的危险目标，因此系统检查 Max-Danger Pooling：

- **单元召回率**：包含真实动态目标的低分辨率单元中，有多少仍检测到动态目标；
- **危险目标保留率**：池化最终选择的高分辨率像素是否确实落在真实动态目标上。

该指标可以发现“高分辨率预测正确，但转换成 PPO 观测后目标消失”的问题。

## 七、360° 全景接缝是否连续

全景图最左列和最右列在物理空间中是相邻方向。普通卷积可能在这里产生边界断裂，因此系统统计：

- 接缝区域动态 IoU；
- 接缝区域动态 Recall；
- 首末列 mask 概率差；
- 该概率差相对于真实 mask 的误差。

这些指标用于检查跨越 `-180°/180°` 边界的障碍物是否被完整识别。

## 八、完整数据集统计原则

训练和验证使用 `perception_training/metrics.py` 中的 `PerceptionMetricAccumulator`。

所有计数和误差会在完整 epoch 上累计后统一计算，而不是先计算每个 batch 的指标再进行简单平均。这样可以避免不同 batch 中动态像素数量不同导致的统计偏差。

当某个距离区间或 batch 没有动态目标时，相关指标返回有限的 `0.0`，同时输出对应的 `support`。分析结果时必须结合 support，不能把“没有样本得到的零值”解释为模型性能为零。

## 九、最佳 checkpoint 选择

最佳模型不再只按照 IoU 选择。默认综合评分为：

```text
IoU + Recall - 动态速度 MAE / 5 - 静态虚假速度均值 / 5
```

这样可以避免选出“分割看起来很好，但速度预测不准确”或“静态区域存在大量虚假速度”的模型。

该综合评分只用于同一训练任务内选择 checkpoint，不作为论文中的独立物理性能指标。

## 十、配置位置

相关参数位于 `perception_training/config/default.yaml` 的 `evaluation` 字段，包括：

- mask 判断阈值；
- 距离分桶边界；
- RL 池化尺寸；
- 全景接缝区域宽度；
- 静态速度 P95 直方图范围；
- checkpoint 综合评分权重。
