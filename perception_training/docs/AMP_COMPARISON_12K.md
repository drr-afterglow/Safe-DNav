# SA-UMNet 12K FP32 与 AMP 对照

更新时间：2026-07-29

## 实验控制

两组实验使用相同 SA-UMNet、12K 数据、train/val/test 场景、随机种子、batch size 256、学习率、损失和 80 轮余弦调度。AMP 组仅开启 FP16 autocast 与 GradScaler。测试集均使用冻结的 1800 条场景 3103/3203/3303 数据。

## 测试精度

| 指标 | FP32 | AMP | AMP-FP32 |
|---|---:|---:|---:|
| Mask IoU | 0.75235 | 0.75366 | +0.00131 |
| Mask F1 | 0.85867 | 0.85953 | +0.00086 |
| Precision | 0.87840 | 0.88291 | +0.00452 |
| Recall | 0.83982 | 0.83735 | -0.00247 |
| 5--10 m IoU | 0.51264 | 0.51037 | -0.00228 |
| 速度 MAE | 0.50865 m/s | 0.50783 m/s | -0.00082 m/s |
| 静态虚假速度均值 | 0.10160 m/s | 0.09607 m/s | -0.00554 m/s |
| Danger Pool 单元召回 | 0.87989 | 0.87484 | -0.00505 |
| Danger Pool 目标保留率 | 0.48918 | 0.47827 | -0.01090 |
| 接缝 IoU | 0.76409 | 0.76115 | -0.00294 |

AMP 最佳 checkpoint 为第 59 轮，验证综合评分 1.46142；FP32 最佳为第 63 轮，评分 1.46067。二者精度总体等价，差异处于约 0--1.1 个百分点。

## 性能

使用同一计时代码统计完整 train+val epoch，排除冷启动轮次：

| 指标 | FP32 | AMP | 变化 |
|---|---:|---:|---:|
| 每轮中位耗时 | 5.739 s | 5.795 s | AMP 慢 1.0% |
| 吞吐中位数 | 1463.7 samples/s | 1449.5 samples/s | AMP 低 1.0% |
| 峰值分配显存 | 2656.8 MB | 2280.8 MB | AMP 节省 14.2% |

当前 SA-UMNet 仅约 14.2 万参数，且计时包含完整评估指标累计，计算规模不足以发挥 RTX 4090 D 的 Tensor Core 吞吐优势，所以 AMP 没有加速。

## 结论

AMP 数值稳定且总体精度不下降，可以用于后续更大 batch 或更大数据训练以节省显存；但在当前 batch size 256 和完整指标设置下没有速度收益。若显存不是限制，FP32 更简单且危险目标保留率略高；当前最佳部署/集成原型仍建议保留 FP32 第 63 轮模型。
