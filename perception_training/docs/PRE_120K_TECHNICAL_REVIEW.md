# 120K 扩大训练前技术审查

更新时间：2026-07-30

## 审查结论

结论：暂不直接扩大到 120000 条。应先修复扫描内运动仿真，并用少量真实 MID-360 数据完成统计标定；随后重新生成一个 12K v2 对照集。只有 v2 标签审计、分布检查和基线回归通过，才放行 120K。

## 1. 传感器模型

现有配置为 360 x 59 度视场、10 m 网络范围、200000 points/s、0.096 s 扫描周期、19200 标称点、5760 条仿真低差异射线、0.02 m 高斯噪声、2% 独立漏点和 0.1 m 最小量程。

优点是没有退化成 6x36 固定多线雷达，连续帧扫描方向不重复，接口参数可配置。风险是扫描序列为工程近似而非官方光机轨迹；远程目录没有真实 MID-360 bag/lvx 录制用于标定，点数、噪声、漏点、占用率、距离分布、帧间重叠、外参和时间同步误差均未核对。风险等级：高。

## 2. 扫描内运动畸变

这是明确的代码级阻断项。

generate_mid360_nonrepetitive_pattern 已生成每条射线 [-0.096,0] s 时间偏移，运行时也支持逐点时间戳和 IMU 去畸变。但采集器 _capture_raw 对整帧所有射线使用同一个 sensor_pos_w/sensor_quat_w，动态球体也使用同一时刻的位置。point_time_offsets 被返回但没有参与静态或动态射线求交。

因此当前帧等价于在扫描结束时刻同时发出 5760 条射线，没有模拟 96 ms 内的无人机运动、障碍物运动、加速度轨迹和去畸变残差。在 2.5 m/s、90 deg/s 上限下，一个扫描周期内理论运动量可达约 0.24 m 和 8.64 deg，不能忽略。风险等级：阻断。

修复要求：

1. 按 point_time_offsets 计算逐射线传感器位姿；
2. 按射线时刻计算动态球位置；
3. 在逐时刻几何上求交，再去畸变到扫描结束坐标；
4. mask、速度标签和输入继续使用同一 noisy Z-buffer 赢家；
5. 增加静态世界+运动传感器、运动球+静止传感器及组合运动解析回归。

## 3. 两帧对齐与标签

已通过：帧间隔 0.096--0.144 s、真实位姿补偿、输入与标签共用 noisy Z-buffer、有效回波和遮挡约束一致、自机三维 FLU 速度已保存、风险评估可严格构造相对速度、12K 全量审计无物理错误。

剩余风险：对齐噪声固定为 0.01 m/0.2 deg，未由真机估计；真实外参、同步偏差和 IMU 噪声未进入分布；动态障碍物仅为球体。风险等级：中高。

## 4. 数据覆盖

| 项目 | 实际值 | 计划下限 |
|---|---:|---:|
| 静态样本 | 25.04% | 25% +/- 2% |
| 远距离动态像素 | 24.29% | >=15% |
| 高速动态像素 | 27.20% | >=10% |
| 接缝动态像素 | 3.81% | >=3% |
| 位移 >=0.2 m | 39.06% | >=15% |
| 旋转 >=8 deg | 29.01% | >=10% |

覆盖全部通过，场景隔离正确。但 12K 每种类型只有 3 个场景；120K 应至少每类 8 个独立场景，不能只增加单场景样本数。

## 5. 资源预算

12K shard 实际约 1.34 GiB。线性估算 120K 数据约 13.4 GiB，80 epoch FP32 约 80 分钟，120 epoch 约 120 分钟。数据盘当前剩余约 23 GiB，保留已有数据后只剩约 9--10 GiB，算力可接受但磁盘安全余量不足。正式采集建议预留至少 18--20 GiB。

## 6. 放行条件

1. 完成逐射线扫描内运动仿真和解析回归；
2. 取得小规模真实 MID-360 录制，统计点数、有效回波率、全景占用率、距离直方图、帧间重叠、噪声和漏点；
3. 明确雷达到机体外参、时间戳基准和 IMU 同步误差；
4. 生成场景隔离的 12K v2，并通过自动审计和人工抽检；
5. 训练 v2 基线，确认总体、远距、速度和风险指标无异常退化；
6. 为 120K 规划每类至少 8 个场景并确认磁盘余量。

## 建议下一步

先实现扫描内运动仿真，不开始 120K 采集。若短期拿不到真机数据，可先完成代码和解析测试并采集小型 v2 pilot；但在真实统计标定完成前，不应称为最终 MID-360 数据集。
